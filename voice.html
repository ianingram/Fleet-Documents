Which path is live, and where the mouth opens

amenti-chat.js was documented as THE PRIMARY PATH, in capitals, and the Terminal never loaded it. An IIFE asked for a core that registered 936 lines too late, the guard evaluated false, and every call site took the inline fallback without a word. Fourteen harnesses reported green across 316 assertions — each one building its own object and testing that. A pane showing which path was live would have caught both.

The reading

Loaded, and used

The column that would have caught the 936-line gap. Registered is where a global is declared; available is the line on that surface from which it can be asked for — the line of a blocking <script src>, or the line itself when written inline. A defer or async tag is never available at parse time at all. A parse-time read before that point is the fault, and it is silent.
