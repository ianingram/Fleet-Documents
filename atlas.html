The panes the instrument deck

Each pane reads a register and shows one part of the ship, so no one reads code to know its state. This Atlas is the map of them all.

How a reading is made

The pattern every subsystem follows — the thing that makes the ship legible.

The real thing exists — a folder of reading rooms, a fleet of tubes, a backup bundle.
A probe or Action walks it and reads what is actually there — not what should be there.
It writes a register — a JSON reading — and commits it. Regenerated, never hand-kept.
A pane fetches the register and shows it. If the register won't load, the pane shows nothing — the empty glass — not a stale number.
You (or a machine) read the pane. The code is never read to know the state.

The doctrine

The principles the whole ship is built on. If you understand these, you understand Amenti.

Readings, not memoriesA register is observed and regenerated, never hand-typed. A hand-kept number drifts the moment the thing it counts changes.
The empty glassReport what is there, not what should be there. A pane with no reading shows nothing rather than yesterday's numbers.
The Silent SignatureThe worst failure is an instrument glowing green while watching nothing. A schedule nobody checks is a promise nobody keeps.
Look firstThe reading is cheaper than the guess. Check the real thing before assuming its state.
A backup never read back is not a backupIt is a file with a hopeful name. The Ark verifies its own bundles, off-provider, daily.
